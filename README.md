# Anime Portfolio

A beautiful anime-themed portfolio website built with Flask.

## Features

- Anime-inspired design
- Flask backend
- Responsive layout
- Easy to customize

## Quick Start

```bash
# Install dependencies
pip install flask

# Run the application
python app.py

# Open in browser
http://localhost:5000
```

## Project Structure

```
anime_portfolio/
├── app.py              # Flask application
├── server.log          # Server logs
└── templates/          # HTML templates
```
